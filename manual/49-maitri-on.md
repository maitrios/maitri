# maitri on...

### Apple M1/M2 chips

[Asahi Alarm](https://asahi-alarm.org/) is a version of Arch for Apple M1/M2 computers built on top of [Asahi Linux](https://asahilinux.org/). You can get maitri running on top of that with some effort. See [the user-driven guide](https://codeberg.org/malik-na/maitri-mac).

### Apple Virtual Machine

You can also install maitri inside a Parallels VM. Quite the cumbersome process, but there's [a user-driven guide](https://github.com/basecamp/omarchy/discussions/452) for that too.

### VirtualBox

VirtualBox is a popular VM runner. [You can run maitri inside that too](https://github.com/basecamp/omarchy/discussions/176). But performance probably won't be great.

### VMware Workstation on Windows 11

Another popular VM runner for Windows. [maitri has been setup inside of that as well](https://github.com/basecamp/omarchy/discussions/572).

### Steam Deck

The Steam Deck runs on Arch, which means you can run maitri on your Steam Deck. Altynbek Orumbayev has [a full setup script and explanation on how to do it](https://github.com/aorumbayev/deckarchy). How cool is that!

### NixOS

maitri is really Arch + Hyprland, but Henry Sipp has [ported the essence of the setup to NixOS](https://github.com/henrysipp/maitri-nix). So if you've been nix-pilled, here's a good starting point. It may or may not stay up-to-date with the latest maitri changes, but it's pretty cool none the less!

### Something else!

If you're trying to get maitri running on a configuration that isn't the default, you should join the #maitri-on-other channel on [our community Discord](https://discord.gg/tXFUdasqhY).
