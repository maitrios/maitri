# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately through GitHub:
[Report a vulnerability](https://github.com/maitrios/maitri/security/advisories/new).

Include what you found, how to reproduce it, and which version or commit you tested. I'll acknowledge the report as soon as I can and keep you posted on the fix.

## Supported versions

Only the latest release and `main` get security fixes.

## Scope

This covers the maitri code in this repository, including the installer ISO build. Problems in upstream software that maitri packages or bundles (Hyprland, Arch Linux, and so on) should be reported to those projects.
